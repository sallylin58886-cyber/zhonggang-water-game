# 中港大排・水循環探險隊

適合國小二至五年級，也適合大人陪伴孩子共玩的繁體中文網頁遊戲。純 HTML、CSS、JavaScript，無須安裝套件、API 金鑰或外部服務。

## Windows 直接開啟

在 GitHub 選擇 `main` 分支，點綠色 **Code → Download ZIP**。下載後對 ZIP 按右鍵，選 **解壓縮全部**，進入解壓縮後的資料夾，連點 `index.html`，使用 Edge 或 Chrome 開啟。請保留 `style.css` 與 `app.js` 在同一個資料夾。更新時請重新下載 ZIP，解壓縮到新資料夾，再開啟新版 `index.html`。

## 預覽

在專案資料夾執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在自己的電腦執行時，使用瀏覽器開啟 `http://localhost:8000`。iPad 與電腦位於同一個區域網路時，可在 Safari 開啟 `http://電腦的區網IP:8000`（需允許防火牆連線）。也可以直接以瀏覽器開啟 `index.html`。

雲端環境的 localhost 屬於雲端主機，不能直接從個人電腦或 iPad 存取。可將專案下載到電腦，依上方方式預覽，或另行部署至靜態網站服務。

## 遊戲規則

- 題庫包含 12 組藍綠配對與 12 道環境守護問答，涵蓋中港大排整治、污水截流、水循環、生態復育、都市防洪與環境守護。
- 每局隨機抽出 4 組配對、6 道問答，共 14 張卡；藍綠配對區與橘色問答區分開顯示，各自洗牌排列。
- 「重新開始」與「再探險一次」都會重新抽題與洗牌，分數及進度歸零；連續兩局的配對題組與問答題組都不會完全相同，但部分題目可能重複。
- 先選藍卡，再選有關聯的綠卡；配對正確得 10 分。
- 測驗模式：每題只作答一次，答對得 10 分；答錯 0 分並顯示正確答案與小知識。
- 配對答錯後，該藍卡及其正確綠卡標記為已作答，自動選取下一張藍卡；剛才誤選的綠卡仍可供其他題目使用。
- 橘卡作答後按「下一題」繼續；也可關閉問答先做其他卡，已作答題目不能重複計分。
- 每個任務只計分一次，總分 100 分。完成 10 個任務顯示實際答對題數及分數。
- 可隨時重新開始。進度不跨重新整理保存。

以大字、觸控按鈕、響應式版面及鍵盤操作設計；水岸生態卡為教育示例，並非中港大排現地物種紀錄。

## 親子共玩與教材範圍

- 小朋友先選答案；大人可協助讀題，先不要直接說出答案。
- 每次配對或問答作答後，都有可展開的「親子想一想」，不計分，也沒有唯一標準答案。孩子單獨玩時可以略過。
- 分數是這次作答的紀錄，並非標準化測驗；配對仍可透過剩餘卡牌推理答案。
- 題庫是水循環、棲地及城市水環境的一般概念教材，不聲稱記錄中港大排的特定工程成果或現地物種。地方導覽仍應搭配官方現地資料。
- 配對使用具體特徵區分答案，例如根固定土壤、樹冠形成樹蔭；避免把廣義的「水岸棲地」限定只能配一種生物。
- 學習詞語已在卡牌或小知識中補充解釋，例如入滲、凝結、棲地、生態走廊、原生植物、污水截流與滯洪。

## iPad 加入主畫面與離線遊玩

本專案已包含 PWA（可加入主畫面的網頁 App）所需檔案，但**提交到 GitHub 不等於已建立可安裝網址**；目前沒有開啟公開網站代管。

### 首次安裝的必要條件

- 先將整個專案的網頁檔案、`manifest.webmanifest`、`sw.js`、`pwa.js` 與 `icons/` 放在同一個支援 HTTPS 的靜態網站。支援網站根目錄或子目錄。
- 如果不希望公開，須使用具備伺服器端登入或存取控制的代管；GitHub 儲存庫的私密設定不等於網站的存取保護，也不要把密碼寫進 JavaScript。代管及存取控制尚未設定。
- 所有遊戲資源須能在登入後正常載入；不要把登入頁面當作遊戲檔案快取。離線資料會留在使用過的裝置上，線上登出不會自動清除裝置裡已下載的遊戲。
- Windows 的 `http://192.168.…:8000` 可連線玩，但在 iPad 上不是安全來源，不能啟用 Service Worker 離線快取。不要只在該網址加入主畫面就假設能離線。
- 電腦開發測試的 `http://localhost:8000` 屬於瀏覽器允許的安全來源例外；這個例外不適用於 iPad 連電腦的區網 IP。

### 有 HTTPS 遊戲網址後，在 iPad 操作

1. 連上網路，用 Safari 開啟遊戲的 HTTPS 網址（不是 GitHub 檔案頁）。
2. 等遊戲上方顯示 **「離線資料已備妥」**；若未成功，保持連線並點「重新檢查」。
3. 點 Safari 的分享按鈕（方框向上箭頭），選 **加入主畫面 → 加入**。如果系統顯示「作為網頁 App 打開」，請啟用。不同 iPadOS 版本的按鈕位置可能不同。
4. 從主畫面圖示重新開啟，確認顯示資料已備妥。
5. 開啟飛航模式，並確認 Wi-Fi 已關閉；關閉遊戲後，再從主畫面圖示開啟，測試配對、橘卡與重新開始。
6. 離線試玩成功後，就能只帶 iPad 出門，電腦不用開機。每次重新開啟或重新整理會開始新局，目前不保存本局進度。

首次下載完成後，全部題庫、樣式和圖示均可離線使用，沒有 CDN 或外部字型依賴。不使用 Safari 私密瀏覽安裝。若移除 App、清除網站資料或系統回收儲存空間，可能需要重新連線下載；出門前建議再次飛航模式試玩。實際 iPad 加入主畫面與離線啟動仍須在實機確認。

### 更新遊戲與開發驗證

- 每次修改快取檔案時，須同步遞增 `sw.js` 的 `VERSION`，讓新資料完整下載後才切換版本。
- 不會在進行遊戲時自動重載。有新版備妥時，按「更新遊戲（重開本局）」並確認，才切換版本並歸零本局。未開啟遊戲時，瀏覽器也可能直接啟用完整下載的新版本。
- 安裝必須成功下載所有必要檔案，才會啟用新版；下載失敗時保留舊的完整版本。快取只清理此遊戲在該路徑的版本，不清除同網站其他 App 的資料。
- 開發時以 localhost 啟動，確認離線資料備妥，再用瀏覽器開發工具切換 Offline，重新整理、關閉分頁再開啟，完成 4 組配對與 6 題問答（全對 100 分），並重新開始至少 5 次。
- 已在 Chromium 模擬驗證離線重新載入、關閉分頁再開啟、計分、抽題與不同畫面寬度；這不等於已在實體 iPad 上完成安裝測試。

### 若決定公開：GitHub Pages 設定方式

以下需由專案擁有者決定啟用，推送程式不會自動公開網站：

1. 到 GitHub 專案 **Settings → Pages**。
2. **Build and deployment → Source** 選 **Deploy from a branch**。
3. **Branch** 選 **main**，資料夾選 **/(root)**，按 **Save**。
4. 等 GitHub 顯示網站發布成功，使用 Pages 頁面提供的 HTTPS 網址。預期路徑是 `https://sallylin58886-cyber.github.io/zhonggang-water-game/`，實際是否已上線須以 Pages 狀態及實際開啟結果確認。
5. 依前面的 iPad 安裝步驟操作。公開 Pages 網站沒有密碼保護，持有網址的人可開啟；如果帳號方案或儲存庫設定不支援，請依 GitHub 頁面提示處理，不必為此先改動儲存庫可見性。

### 自動離線 smoke test（開發用）

遊戲執行不需要 Node.js；以下僅供已有 Playwright 與 Chromium 的開發環境驗證。在專案目錄啟動靜態伺服器後執行：

```sh
node tests/pwa-smoke.cjs
```

可用 `GAME_URL` 指定測試網址（含結尾 `/`）；瀏覽器已由系統安裝時，可用 `CHROMIUM_PATH` 指定 Chromium 執行檔。測試使用隔離瀏覽器資料，覆蓋離線重載、關閉分頁再開啟、全對 100 分、5 次抽題、版面與其他應用快取保留，不會更改題庫。
